Privacy Policy

Recruiting Tracker. Last updated September 29, 2026.

Who this applies to

Recruiting Tracker is a personal application with a single user, its owner. It runs on the owner's own computer and is not offered to the public.

Google account data the application accesses

When the owner connects their Google account, the application accesses:

  • Gmail messages: to send emails the owner has written, to read replies and delivery failure notices for those emails, and to move them under a label.
  • Gmail labels and filters: to create the label and the filter that file those replies.
  • Google Calendar events: to create events for calls the owner schedules.

How the data is used

The data is used only to provide the features listed above to the owner. It is not used for advertising, and it is not used to train any machine learning model.

Where the data is kept

All data stays on the owner's own computer. The application has no server of its own and does not transmit Google account data anywhere except back to Google to carry out the owner's requests.

Sharing

Google account data is not sold, shared with, or transferred to anyone.

Removing access and data

The owner can disconnect the Google account inside the application, which deletes the stored sign-in from the computer. Access can also be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Recruiting Tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
