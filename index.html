Recruiting Tracker

A personal tool for organizing an internship search.

What it is

Recruiting Tracker is a private application that runs on its owner's own computer. It keeps track of firms, open roles, networking contacts and scheduled conversations in one place.

How it uses a Google account

The owner can connect their own Google account so the application can:

  • send emails the owner has written and approved,
  • check for replies to those emails,
  • file those replies under a label in the owner's mailbox,
  • add scheduled calls to the owner's calendar.

The application is not offered to the public and has a single user, its owner.
